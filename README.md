# メロディをドレミに

音声ファイルから歌声を分離し、メロディをドレミ・簡易楽譜・音程グラフで確認する、Python と FastAPI のアプリです。

## 主な機能

- 音声の開始位置と解析する長さ（1〜60秒）を指定
- Demucs によるボーカル分離と、分離結果のキャッシュ
- pYIN または torchcrepe による音程推定
- 分離済みの歌声を直接解析
- 解析に使った歌声の試聴
- ドレミ表示・簡易楽譜表示・合成音によるメロディ再生
- 元の音程と補正後の音程をグラフで比較

テンポの指定は簡易楽譜の音符の長さの表示に使います。テンポの自動検出や、正確な自動採譜を保証するものではありません。

## 実行環境

- Python（元の開発環境のバージョンは未確認）
- Python ライブラリをインストールするためのインターネット接続
- 音声処理に必要な FFmpeg をインストールし、`ffmpeg` コマンドが使える状態にする

添付されたコードから依存関係を抽出しています。元の環境のライブラリバージョンは未確認のため、`requirements.txt` はバージョン未固定です。新規環境でのインストール・音声解析は未検証です。PyTorch・TorchAudio・Demucs などの組み合わせによってはバージョン調整が必要です。

## 起動方法（Windows・コマンドプロンプト）

このフォルダをコマンドプロンプトで開き、実行します。

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

ブラウザで http://127.0.0.1:8000 を開きます。終了するときはコマンドプロンプトで `Ctrl+C` を押します。`index.html` を直接開くのではなく、上記のサーバー経由でアクセスしてください。

すでに動作している `.venv` がある場合は、その環境をそのまま利用できます。作り直す必要はありません。

## 起動方法（macOS・Linux）

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

FFmpeg は Python の依存一覧とは別に、OS にインストールしてください。

## 使い方

1. 音声ファイルを選びます。
2. 開始位置と解析する長さを指定します。初回は短い区間から試してください。
3. 必要に応じて「分離済みの歌声を使う」「torchcrepeで音程を解析する」を選びます。
4. 「解析する」を押します。
5. ドレミ・簡易楽譜・音程グラフを確認し、歌声や楽譜を再生します。

歌声の分離は CPU で実行され、数分かかる場合があります。Demucs のモデルは初回使用時にダウンロードされる場合があります。

## 自動生成されるデータ

`previews/` と `vocal_cache/` は起動時に自動作成されます。GitHub に含める必要はありません。

- `previews/`：解析に使った歌声の試聴用 WAV
- `vocal_cache/`：分離結果を再利用するための WAV

これらは自動削除されません。容量が増えたら、アプリを終了してから不要なデータを削除できます。削除した試聴音声は再生できなくなり、キャッシュを削除した音声は次回に再分離します。

## GitHub に登録する際の注意

- `.venv/`、`__pycache__/`、生成音声は登録しません。
- 添付のルートの `app.py` は、別フォルダ `vocal-melody/` のコードを参照していません。この版を登録する場合、そのフォルダは必要ありません。
- 下書きのテキスト文書、未使用のフォント、テスト用音声は、登録用フォルダにコピーしないでください。
- 公開する音声・フォントなどは、公開・再配布できるものだけを含めてください。
- `.gitignore` は、すでに Git で追跡しているファイルを自動で登録解除するものではありません。

## 公開について

GitHub ではソースコードを共有できます。音声解析には Python サーバーが必要なため、GitHub Pages だけではアプリ全体を動かせません。

この起動手順は自分のパソコン内での利用を想定しています。現在のコードには認証やアップロードサイズ制限がないため、外部公開する際は別途対応が必要です。
